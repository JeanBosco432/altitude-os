# ALTITUDE Trade V6.2

Version de stabilisation des vues analytiques.

- Dashboard toujours rendu, même avec un historique ancien/incomplet.
- Comptes: Deriv, JustMarkets et FundedNext visibles séparément.
- Historique robuste par période et filtres.
- Statistiques robustes: PnL, win rate, profit factor, expectancy R, drawdown, risque, streaks, breakdowns.
- Courbes et diagrammes visibles même avant les premiers trades.
- Migration défensive des données V5/V6.
- Erreur technique affichée directement dans l'interface si un nouveau cas non prévu apparaît.

Conserver votre `config.js` existant lors de la copie afin de garder votre configuration Supabase.
